# 设计规范 — 编辑式图谱艺术

## 1. 纸面与色彩

| 元素 | 规格 |
|---|---|
| 纸面背景 | 纯白 `#FFFFFF` |
| 主墨色 | 墨蓝 `#2A3B4D`，透明度阶梯 i70→i08（70%→8%） |
| 强调色 | 珊瑚 `#C84A31`，全页仅一处单强调（最强通路 / 最高值 / 关键实体） |
| 辅助 | `inkA(a)` / `accA(a)` 动态函数生成带透明度色值，禁止硬编码 rgb |
| 网格刻度 | 点阵刻度语言：细点 / 短刻度线，i15–i25 透明度 |

## 2. 三主题系统

```
THEMES = { mono, ink, coral }
```

| 主题 | INK | ACC | 气质 |
|---|---|---|---|
| MONO（默认） | 近黑墨色 | 深灰 | 报纸黑白极简 |
| INK | #2A3B4D 墨蓝阶梯 | 墨蓝加粗 | 蓝图/制图感 |
| CORAL | 墨蓝 | #C84A31 | 编辑部单强调 |

切换机制：`let CUR/INK/ACC/i70…i08` 全局重赋 + `applyPaletteVars()` 更新 CSS 变量 + `renderAll()` 全量重绘。任何新色值必须经动态函数，保证三主题全过。

## 3. 字体排印

| 角色 | 字体 | 用法 |
|---|---|---|
| 图题（t） | Georgia / 衬线 | 中文诗意图名，较大字号 |
| 副题（sub） | SF Mono / 等宽 | 英文类型名 · 中文类型名，小号大写风格 |
| 角标（kicker） | SF Mono | FIG. 编号、数据计数 |
| 注脚（note） | 等宽小号 | 一句话数据旁白 |

## 4. 动效三档

1. **入场**：draw（描线）、pop、rise、growX/growY（从基线生长）。
2. **永续**：sway、bob、breathe（呼吸透明度）、flow（沿路径巡航）、tw、fall、spin——让数据成为"活的有机体"。
3. **响应**：hover tooltip（全部图型标配）、REPLAY 重播按钮、专属交互（拖拽 / 点击吹散 / hover 拨动）。

## 5. 可访问性

- `prefers-reduced-motion: reduce` 时：永续动效降级为静态定格；力导向图同步跑 50 tick 物理沉降后直接渲染终态。
- hover tooltip 提供文字化数据读取路径。

## 6. 物理与动效实现要点

- **力导向**（FIG.20）：rAF 循环三段式 `tick()`（斥力 1400/d² + 弹簧 (d-90)×0.004 + 阻尼 0.86）→ `render()` → `step()`；改物理循环要一次改对，不打补丁。
- **巡航光点**：SMIL `animateMotion` 沿路径流动。
- **零依赖**：全部 SVG + 原生 JS，无外部 CDN/字体/库，离线可开。

## 7. 布局节奏

- 图卡网格纵向流；每卡 = kicker（FIG.N + 类型）+ 图题 + 副题 + 画布 + 注脚。
- 族与族之间留大空隙，配族标题；整页如杂志数据专栏翻页。
